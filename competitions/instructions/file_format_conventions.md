# Repository-Wide File Format Conventions

This file fixes the file format defaults for every future commit. The future session must follow the format defaults below unless an individual commit instruction file overrides a specific format with a documented reason.

## Defaults by Purpose

| Purpose | Format | Extension | Notes |
|---------|--------|-----------|-------|
| Narrative deliverable | Markdown | `.md` | GitHub Flavored Markdown, single dashes only |
| Final formal report | Portable Document Format | `.pdf` | Generated from LaTeX or from Markdown via `pandoc` |
| Structured single-record output | JSON | `.json` | UTF-8, two-space indent, trailing newline |
| Streaming append-only output | JSON Lines | `.jsonl` | One JSON object per line, no comma between lines |
| Configuration | YAML | `.yaml` | Two-space indent, `yamllint -d relaxed` clean |
| Python project metadata | TOML | `.toml` | PEP 621 compliant |
| High-volume sensor or coordinate data | Parquet | `.parquet` | Snappy compression, dictionary encoding for enums |
| Human-review sample | CSV | `.csv` | UTF-8, comma delimiter, RFC 4180 quoting, header row |
| JSON Schema definition | JSON Schema 2020-12 | `.schema.json` | `$schema` field set to draft 2020-12 |
| Protocol Buffers definition | Protocol Buffers 3 | `.proto` | `syntax = "proto3";` header |
| Avro schema | Apache Avro | `.avsc` | JSON-encoded schema |
| Source code: orchestration and analysis | Python | `.py` | Python 3.10 plus, `ruff format` clean, `ruff check` clean |
| Source code: real-time control | C++ | `.cpp` | C++20, header-only style preferred |
| Source code: high-throughput simulation | Rust | `.rs` | Rust 2021 edition, `cargo fmt` clean |
| Vector schematic (low density) | SVG | `.svg` | Allowed only for static diagrams under 100 KB |
| ASCII diagram or robot path summary | Plain text | `.txt` | 80 columns max, 60 lines max |
| Mermaid diagram | Markdown fenced block | inline in `.md` | `mermaid` language tag |
| Static chart | PNG | `.png` | 1920 by 1080 maximum, generated by `matplotlib` |
| Interactive dashboard | HTML | `.html` | Self-contained, generated by `plotly`, under 5 MB |
| Plain log | Text | `.txt` | One event per line, ISO 8601 timestamp prefix |
| Analytical store | DuckDB | `.duckdb` | Generated by script from Parquet inputs |
| Notebook | Jupyter | `.ipynb` | Outputs cleared before commit |
| License | Plain text | `.txt` | Verbatim license text |

## Authoring Rules

- All instruction files use single dashes only.
- All instruction files use black text only.
- Mermaid diagrams must use the default theme. Do not set `themeVariables` or color overrides.
- Generator scripts must accept a `--seed` flag and a `--out` flag. Default seed is 20260509.
- Generator scripts must be deterministic for a fixed seed.
- All Python files at the top of the file must include a module docstring describing inputs, outputs, and the relevant regulatory section.
- All Python files must avoid wildcard imports.
- All YAML files must avoid tab indentation.
- All Parquet files must include a `meta_seed` integer column and a `meta_iteration_id` string column to support the future Commit 5 comparison protocol.

## SVG vs. ASCII vs. Mermaid Decision Rule

The future session uses the following decision rule when choosing a diagram format.

- If the diagram contains more than 200 visual elements, use ASCII text in a `.txt` file or aggregate the content first.
- If the diagram contains 50 to 200 visual elements and is structural (boxes and arrows), use Mermaid inside a `.md` file.
- If the diagram contains fewer than 50 visual elements and benefits from vector rendering, use SVG.
- Time-series with more than 100,000 points: never SVG. Aggregate to per-second or per-minute summary, then plot as PNG via `matplotlib`. The full per-millisecond record stays in Parquet.

## Naming Conventions

- Use snake_case for all directory names, file names, and Python identifiers.
- Use kebab-case only for top-level competition directory names that already exist (`new-trial`, `national-24-7-trial`, `patient-journey`). New directories follow snake_case.
- Use UPPERCASE only for `README.md`, `LICENSE.txt`, `CHANGELOG.md`, and `CITATION.cff`.
- Iteration files use `run_<id>.parquet` where `<id>` is a five-digit zero-padded integer. Example: `run_00001.parquet`.

## Source Files Cited

- `ruff.toml`. Source for the `line-length = 120`, `target-version = "py310"`, and `select = ["E", "F", "W"]` rules that the future Python files must satisfy. The `per-file-ignores` table also documents acceptable exceptions for `competitions/**/*.py` patterns; the future session must add a similar entry for `competitions/glioblastoma-1hr-trial/**/*.py` if it requires such an exception.
- `requirements.txt`. Source for the package versions that the future `pyproject.toml` must remain compatible with.
- `.github/workflows/ci.yml`. Source for the matrix of Python 3.10, 3.11, and 3.12 that every Python file must work under.
