**Comprehensive developments for integrating physical AI into oncology clinical trials, by Claude Code Opus 4.7, Cowork; with Assistance from ChatGPT 5.5 Thinking and Google Gemini Search.**

This repository provides production-ready configurations, validated pipelines, and integration guides for deploying robotic systems, digital twins, and embodied AI agents in oncology. 

**5/11: v3.9.2 (Generative AI LaTeX Paper Templates)** *Ten distinct single column academic LaTeX paper templates spanning ten oncology research perspectives* - Ten ready-to-use Overleaf compatible templates at generative-ai/templates/ (Clinical Trial Protocol, Robotic Surgery Engineering, Bioinformatics and Genomics, Regulatory and FDA Submission, Patient-Centered Outcomes, Health Economics and Outcomes, AI and Machine Learning Methods, Digital Twin and Simulation, Multi-Site Federation, Translational Oncology) each shipping with main.tex, new_paper.sty, references.bib, README.md, and per-section .tex files under sections/. Each template ships with a blank single-line Keywords slot on page one, a single illustrative paragraph per section, and a three-row Table 2 layout using `>{\raggedright\arraybackslash}p{3.4cm}` / `p{4.6cm}` / `p{5.4cm}` column widths to prevent rivers. Templates are inspired by leading CC BY templates such as the MDPI single column article template and other journal-style CC BY templates, adapted into ten visually distinct variants without preprint editing formatting and without line numbers in columns. ## Responsible use

This repository is complementary and open source, please implement code safely and responsibly. Intended audience: engineers building physical AI systems (robotics, ML, integration, and validation) for clinical trial settings.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/kevinkawchak/physical-ai-oncology-trials.git
cd physical-ai-oncology-trials

# Install base dependencies
pip install -r requirements.txt

# Verify framework availability
python scripts/verify_installation.py

# Detect available simulation frameworks
python unification/cross_platform_tools/framework_detector.py
```
