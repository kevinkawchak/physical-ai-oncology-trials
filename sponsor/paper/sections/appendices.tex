[CLAUDE CODE INSTRUCTION: Generate 24 sponsor activity scripts, one per simulation hour.
Each script reads the corresponding hour directory from new-trial/ and generates sponsor
directives. All scripts follow this naming convention:

  sponsor/paper/scripts/hourly/sponsor\_hour\_00.py through sponsor\_hour\_23.py

1. Read new-trial/hour-XX/hour\_XX\_simulation.md for the minute-by-minute log
2. Read new-trial/hour-XX/hour\_XX\_robot\_logs.md for robot telemetry
3. Read new-trial/hour-XX/hour\_XX\_patient\_records.md for patient status
4. Read new-trial/hour-XX/hour\_XX\_psl\_scores.md for PSL assessment
5. Generate sponsor decisions at 5-minute intervals (12 decisions per hour)
6. Output a JSON file: sponsor/paper/scripts/hourly/output/sponsor\_hour\_XX.json
7. Each decision must include: timestamp, decision\_type, agent\_responsible,
   confidence\_score, action\_taken, escalation\_required (boolean), rationale
8. Parse patient arrivals, procedure completions, adverse events, and robot status
   changes from the simulation logs to trigger appropriate sponsor responses]
