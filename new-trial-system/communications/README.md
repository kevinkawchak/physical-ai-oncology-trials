Thirteen plain-text messages, every one of which carries **Pancreatic Cancer LLM
Clinical Trial System: From IND to Protocol to Legislation, Funding, and AI Peer
Review** as its first attachment. The paper is at
[new-trial-system/final-new-trial/update-final](https://github.com/kevinkawchak/physical-ai-oncology-trials/tree/main/new-trial-system/final-new-trial/update-final).

**Nothing here has been sent.** Every file is a draft the author compiles,
verifies and sends by hand. Every recipient address must be confirmed against the
organization's current published contact page before use, and every file carries
a `BEFORE SENDING` or `NOTES FOR THE AUTHOR` block naming what to check first.

## Claims every message is held to

Each message repeats, in its own register, the same four bounds. They are the
reason this set can be sent at all.

1. Model peer review is not regulatory review. Nothing here substitutes for an
   institutional review board, an FDA information request, or a data and safety
   monitoring board.
2. The investigational agent is not described as first-in-human anywhere. It is
   already in Phase 3 evaluation; the supportable claim is the first prospective
   clinical evaluation of the integrated surgical and advisory workflow, subject
   to FDA and institutional confirmation.
3. UC San Diego is not a sponsor, site, or endorser of this work, and no message
   may imply that it is.
4. H. R. 9510 is an author-drafted legislative proposal. It has not been
   introduced and is not pending before Congress.
