Nine follow-up emails to the nine funding organizations whose application
archives are in
[funding/pdac-funding-applications/applications/emailed-source](https://github.com/kevinkawchak/physical-ai-oncology-trials/tree/main/funding/pdac-funding-applications/applications/emailed-source).
Each file follows the format of that organization's original
`email-app-xx-*.txt`: a `FROM`, a `TO` and `CC`, a `SUBJECT`, a body between
`=== BODY ===` and `=== END BODY ===` closing with the author's name, company and
**August 14, 2026**, then an ordered attachment list and a `BEFORE SENDING`
checklist.

## Attachment rule

**Attachment 1 is always the paper**, *Pancreatic Cancer LLM Clinical Trial
System: From IND to Protocol to Legislation, Funding, and AI Peer Review*, Draft
1.0, compiled from
[new-trial-system/final-new-trial/update-final](https://github.com/kevinkawchak/physical-ai-oncology-trials/tree/main/new-trial-system/final-new-trial/update-final).
Attachments 2 through 5 differ by organization and are listed in each file.

Every address is carried forward from the original application file and **must be
re-confirmed against the organization's current published contact page** before
any of these is sent. Where an open solicitation requires a portal submission,
the email is a courtesy notice only.

Nothing in this directory has been sent, and nothing here is a submission of
record.
