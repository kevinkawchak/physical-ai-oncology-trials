# San Francisco Municipal Code Update - Physical AI Trial Site Regulations

**Version**: 2.9.0
**Last Updated**: March 2026

## Overview

Proposed amendments to the San Francisco Planning Code, Building Code, and
Health Code for Physical AI oncology clinical trial site permit, zoning, and
operational requirements. Establishes San Francisco as the location of the
first Physical AI oncology clinical trial site in California.

## Key Provisions

- Zoning: Conditionally permitted in NC, MUG, PDR, DTG, C-3, and Medical Use districts
- Conditional use permit with Physical AI System Deployment Plan
- Patient Flow Analysis based on 168-patient simulation data
- Building permit requirements for surgical suites, RT vaults, server rooms
- Health Care Facility Operating License with PSL compliance
- Quarterly inspections and public reporting
- Noise and environmental standards for 24-hour operations
- Transit-accessible location preference (within 1/4 mile BART/Muni)
