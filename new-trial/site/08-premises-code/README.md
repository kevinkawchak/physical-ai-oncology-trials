# Physical AI Oncology Trial Site Premises Code

**Version**: 2.9.0
**Last Updated**: March 2026

## Overview

Safety, access, security, environmental, and operational standards for
Physical AI oncology clinical trial site premises. Covers the physical site,
grounds, security systems, patient flow, robot operational zones, emergency
access, and waste management for 24-hour autonomous operations.

## Key Provisions

- Five access control zones (Public, Patient, Clinical, Technical, Administrative)
- 24-hour physical security with video, access control, and intrusion detection
- Patient arrival and circulation for 168+ patients per day
- Robot movement corridors separated from patient pathways
- Robot maintenance bay for 3 simultaneous systems
- Emergency evacuation with Physical AI safe-shutdown procedures
- Medical and radioactive waste management
- Interior environment standards for 24-hour operations
