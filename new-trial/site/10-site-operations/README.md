# Physical AI Trial Site Activation and Standard Operating Procedures

**Version**: 2.9.0
**Last Updated**: March 2026

## Overview

Standard operating procedures for Physical AI oncology clinical trial site
activation and 24-hour daily operations. Covers the site activation checklist,
three-shift management, patient processing workflow, Physical AI system daily
checks, utilization management, quality assurance, and adverse event management.

## Key Provisions

- Site activation checklist (regulatory, facility, staffing, documentation)
- Three-shift structure (06:00-14:00, 14:00-22:00, 22:00-06:00)
- Patient processing workflow from arrival to departure
- Daily Physical AI system verification checks
- Utilization management based on simulation data
- Quality indicators benchmarked against 24-hour simulation baseline
- Adverse event management targeting same-hour resolution
