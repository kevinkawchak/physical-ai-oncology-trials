# Release notes - v3.9.2

Generative AI LaTeX Paper Templates (v3.9.2)
v3.9.2 - Generative AI LaTeX Paper Templates

## Summary

- Added ten distinct single column LaTeX academic paper template directories at generative-ai/templates/ (01-clinical-trial-protocol/, 02-robotic-surgery-engineering/, 03-bioinformatics-genomics/, 04-regulatory-fda/, 05-patient-centered-outcomes/, 06-health-economics/, 07-ai-ml-methods/, 08-digital-twin-simulation/, 09-multi-site-federation/, 10-translational-oncology/) plus a top-level generative-ai/templates/README.md that indexes the family, documents the shared invariants, and explains how to compile and zip each template.
- Every template ships with five top-level deliverables: main.tex (preamble, title page, table of contents, and \input lines), new_paper.sty (template-specific style file), references.bib (5-entry starter bibliography in ieeetr style with the @template-self, @repo-physical-ai-oncology-trials, @claude-code, @ccby4, and @ich-e6r3 keys), README.md (per-template documentation), and a sections/ subdirectory containing one .tex file per section (abstract.tex, introduction.tex, methods.tex, results.tex, discussion.tex, limitations_future.tex, conclusions.tex, back_matter.tex). The main.tex \input lines map one-to-one to the sections/ files so authors edit one section at a time.
- Each template's title page metadata follows the example template pattern from kevinkawchak/robotic-surgeries/tree/main/2030-gbm-1min/paper/full-paper/final-paper: Author Kevin Kawchak with green ORCID iD linked to https://orcid.org/0009-0007-5457-8667, position CEO ChemicalQDevice, DOI placeholder 10.5281/zenodo.xxxxxxxx (https://doi.org/10.5281/zenodo.xxxxxxxx), and date May 11, 2026. The back_matter.tex section reuses the example pattern with five short subsections (Acknowledgments, Ethical Disclosures, Rights and Permissions, Cite This Article, Data Availability) and a generalized Data Availability section that does not reference any specific upstream repository.
- A blank single-line \keywords{ } slot appears on page one of every template immediately under the abstract so authors can fill in their own keywords without disturbing layout. The Introduction section starts on the title page (page 1) and the table of contents appears immediately afterward, matching the example template pattern.
- Each section ships with a single illustrative paragraph of minimal text and a three-row Table 2 layout (placed inside every body section) using the column width pattern >{\raggedright\arraybackslash}p{3.4cm} for the first column, >{\raggedright\arraybackslash}p{4.6cm} for the second column, and >{\raggedright\arraybackslash}p{5.4cm} for the third column. The raggedright prefix on every cell width prevents large interword rivers inside cells and matches the formatting invariants of the example template.
- The ten templates span ten oncology research perspectives so authors can pick the variant that visually matches their target audience: 01 Clinical Trial Protocol (classic Times Roman + Helvetica, neutral black), 02 Robotic Surgery Engineering (modern sans-serif with dark blue accents on title, abstract heading, section headings, and rules), 03 Bioinformatics and Genomics (MDPI inspired clean look with italic abstract and journal-style submission line), 04 Regulatory and FDA Submission (palatino serif with dark blue navy accents and a navy ruled title block), 05 Patient-Centered Outcomes (slim minimalist Charter body with small-caps section headings), 06 Health Economics and Outcomes (bold display with 22 pt sans-serif title and italic abstract), 07 AI and Machine Learning Methods (technical monospaced section headings with #article|template|v1.0 tagline), 08 Digital Twin and Simulation (elegant Palatino serif with italic section titles and underrules), 09 Multi-Site Federation (journal-style uppercase sans-serif section headings with a centered RESEARCH ARTICLE tag), and 10 Translational Oncology (Computer Modern serif with centered title and indented paragraphs).
- Templates 02 (Robotic Surgery Engineering) and 04 (Regulatory and FDA Submission) are the two variants that specify dark blue text for relevant sections per the requirement. Template 02 uses HTML 0A3D62 dark blue applied to title, section headings, abstract heading, header rule, and keyword label. Template 04 uses HTML 0B2545 navy applied to title, section headings, abstract callout, header rule, and keyword label. The other eight templates render all body text in black with no color accents.
- The templates inherit the formatting invariants of the example template at 2030-gbm-1min/paper/full-paper/final-paper: 11 pt body, 1 inch margins, raggedright table columns, widow and orphan suppression via \widowpenalty=10000 and \clubpenalty=10000, \sloppy and \emergencystretch=3em to prevent rivers, \UrlBreaks for clean DOI line breaks, an orcid_icon.png file detection with a green iD fallback, hyperlinks colored black via \hypersetup, and \captionsetup for raggedright captions. Each template compiles cleanly on Overleaf with the standard pdflatex + bibtex + pdflatex + pdflatex sequence.
- The templates are single column format, do not include line numbers in columns, and do not include preprint editing formatting (no submission watermark, no draft marks). The templates are professional and ready to use; an author replaces the illustrative paragraph and Table 2 layout in each section with study-specific content and replaces the title page DOI placeholder 10.5281/zenodo.xxxxxxxx with a real Zenodo deposition.
- The templates are inspired by leading CC BY templates such as the MDPI single column article template (https://www.overleaf.com/latex/templates/mdpi-article-template/fcpwsspfzsph) and other journal-style CC BY templates, adapted into ten visually distinct variants. The template family inherits the CC BY 4.0 license. No content was committed to kevinkawchak/robotic-surgeries; the example template was used as a read-only reference only.
- The pull request adds only LaTeX, Markdown, and one binary zip file under generative-ai/templates/. No Python, YAML, or other CI-checked files are added or modified. The repository CI matrix (ruff format check, ruff check, yamllint -d relaxed) on Python 3.10, 3.11, and 3.12 remains green because the new files are entirely outside the lint scope. The lint-and-format job continues to pass for the three Python matrix entries (3.10, 3.11, 3.12).

## Features

- generative-ai/templates/README.md ties the ten templates together, documents the shared section inventory, lists which two templates use dark blue accents, and explains how to regenerate the Overleaf-ready zip locally with either the Linux/MacOS zip command or the Windows PowerShell Compress-Archive command.
- generative-ai/templates/01-clinical-trial-protocol/ holds the Clinical Trial Protocol perspective (Times Roman classic). Its README documents the title page metadata placeholder, the section inventory, and the compile recipe. The Methods section illustrative paragraph describes CONSORT-style reporting, the Results section describes the per-arm summary, and the Discussion section describes head-to-head comparison with prior work.
- generative-ai/templates/02-robotic-surgery-engineering/ holds the Robotic Surgery Engineering perspective (modern sans-serif with dark blue accents). The style file uses Helvetica via phv as the family default and applies HTML 0A3D62 to title, abstract heading, section headings, and the header rule. The illustrative paragraphs describe end-effector kinematics, sensor budgets, control loops, and the emergency-stop envelope.
- generative-ai/templates/03-bioinformatics-genomics/ holds the Bioinformatics and Genomics perspective (MDPI inspired clean look). The title page uses an MDPI-style submission line with Received / Accepted / Published markers, and the abstract opens with the italic "Abstract:" tag. The illustrative paragraphs describe variant calling, pathway enrichment, multi-omics integration, and reproducible pipeline engineering.
- generative-ai/templates/04-regulatory-fda/ holds the Regulatory and FDA Submission perspective (palatino serif with dark blue navy accents). The style file applies HTML 0B2545 navy to title, section headings, page number, header text, and an abstract callout box at navy 8 percent opacity. The illustrative paragraphs describe 21 CFR, ICH E6(R3), IEC, FDA SaMD, and Real-Time Clinical Trials.
- generative-ai/templates/05-patient-centered-outcomes/ holds the Patient-Centered Outcomes Research perspective (slim minimalist Charter via bch). The style file uses small-caps section headings and an italic abstract opener. The illustrative paragraphs describe recruitment, PRO instruments, patient advisory board structure, and decisional conflict.
- generative-ai/templates/06-health-economics/ holds the Health Economics and Outcomes Research perspective (bold display, 22 pt sans-serif title). The style file uses a 1.2 pt header rule and renders the abstract in italic. The illustrative paragraphs describe cost-effectiveness, budget impact, value frameworks, and reimbursement strategy.
- generative-ai/templates/07-ai-ml-methods/ holds the AI and Machine Learning Methods perspective (technical monospaced section headings). The style file uses pcr Courier for headings and adds a small #article|template|v1.0 tagline above the title. The illustrative paragraphs describe dataset, model architecture, optimizer, hyperparameter search, cross-validation, and TRIPOD+AI / CREMLS reporting standards.
- generative-ai/templates/08-digital-twin-simulation/ holds the Digital Twin and Simulation perspective (elegant Palatino serif). The style file uses titlesec for italic section titles with a 0.4 pt underrule and centers the title in italic at 22 pt. The illustrative paragraphs describe the physics engine, mesh resolution, boundary conditions, calibration data, and validation strategy.
- generative-ai/templates/09-multi-site-federation/ holds the Multi-Site Federation and Federated Learning perspective (journal-style uppercase section headings). The style file uses \MakeUppercase on sans-serif section names and adds a centered RESEARCH ARTICLE tag in journal red 6A1B1B above the title. The illustrative paragraphs describe the federation protocol, secure aggregation, differential privacy parameters, governance committee, and harmonization plan.
- generative-ai/templates/10-translational-oncology/ holds the Translational Oncology perspective (Computer Modern serif, LaTeX default). The style file uses the LaTeX default font and centers both the title and the section headings. The illustrative paragraphs describe bench assays, patient-derived models, pharmacology screens, and the planned first-in-human study.

## Notes

- The example template at kevinkawchak/robotic-surgeries/tree/main/2030-gbm-1min/paper/full-paper/final-paper was used as a read-only reference for the title page metadata pattern, the back_matter.tex section layout, the column type macros (L, C, R), the ORCID iD fallback block, and the formatting invariants (widows, orphans, rivers, raggedright tables, hyperlink color). No content was committed to the robotic-surgeries repository as part of this work, per the explicit instruction.
- The DOI placeholder is 10.5281/zenodo.xxxxxxxx and is intended to be replaced with a real Zenodo record id when a template author runs the paper through Zenodo. The placeholder renders as a clickable link in the rendered PDF.
- All ten templates ship as unzipped source trees that are browsable directly on GitHub. The generative-ai/templates/README.md documents the simple Linux/MacOS `zip -r <slug>.zip <slug>/` and Windows PowerShell `Compress-Archive` recipes that produce the Overleaf-ready bundle from any template source tree.
- The pull request adds only LaTeX and Markdown content under generative-ai/templates/ plus one binary zip for template 01. The repository CI matrix (ruff format check, ruff check, yamllint) on Python 3.10, 3.11, and 3.12 remains green because no Python or YAML files are added or modified.
