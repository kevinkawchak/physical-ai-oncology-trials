\section{Thirty-Six Months, Three Gates}

The program is scoped to thirty-six months rather than five years, because an
ARPA bet should either produce a recommended Phase 2 dose and a clean safety set
or be stopped. Gate 1 closes the regulatory and bench work, Gate 2 closes the
first treated cohort, and Gate 3 closes escalation. A gate that fails ends the
program; it does not trigger a replan.
