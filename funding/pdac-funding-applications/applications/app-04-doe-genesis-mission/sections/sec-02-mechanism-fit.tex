\section{What Runs Where}

The Genesis Mission's data infrastructure work assumes instruments that emit
open, curated records. This program's contribution is a topology in which the
model is useful and still cannot act: everything that could influence a motion
sits inside the hospital boundary, and nothing that leaves it can return.
