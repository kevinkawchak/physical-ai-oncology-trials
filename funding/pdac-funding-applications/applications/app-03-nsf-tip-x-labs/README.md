A concept outline to the **NSF Directorate for Technology, Innovation and
Partnerships (TIP), X-Labs**, dated **August 3, 2026**.

## Why this recipient

Chapter II of *Science: A New Golden Age* names X-Labs as "the first federal
program designed to fund independent research organizations outside traditional
academia," and supports it with an institutional-fit table scoring universities,
corporate laboratories, federal laboratories, and new institutions. This
application makes the organization-type argument rather than the money argument:
the five activities the program needs are not all covered by any existing
performer type.

## The ask

| Item | Value |
|:--|:--|
| Mechanism | X-Labs, independent research organization |
| Term | 5 years |
| Direct cost | $700,000 per year, $3,500,000 total |
| Cost share | None requested |
| Annual public good | Bench method, logging schema, escalation dataset, full verification package |
| Partner site | UC San Diego Moores Cancer Center, feasibility stage only |

## Figures, and why each type was chosen

| Fig | Type | Why this platform |
|:--|:--|:--|
| 1 | d2-type scored grid | The subject is a **matrix**: five activities against four performer types. A true grid is the only honest way to show that no column is complete |
| 2 | diagrams-python-type clusters | The subject is **two organizations doing the same four functions**. Clustered glyph tiles read as organizations; boxes and arrows would read as a process |
| 3 | mermaid-type flowchart | The subject is a **pathway with a branch**: what happens if the first site agreement does not execute. Mermaid's decision node carries that directly |

No plantuml-type or graphviz-type figure appears here. This application argues
about organization types, not about authority or dependency, so neither
vocabulary earns a place.
