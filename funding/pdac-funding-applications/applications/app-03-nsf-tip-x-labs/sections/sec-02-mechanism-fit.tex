\section{Why No Existing Institution Fits}

Chapter II's institutional-fit table scores four performer types against seven
activities. Applied to the five activities this program actually needs, the
result is the gap the X-Labs mechanism was created to fill: every existing type
covers some, none covers all five, and the two that could operate on patients
are the two least able to release the software openly.
