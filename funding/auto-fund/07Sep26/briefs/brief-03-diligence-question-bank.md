## Why a question bank rather than an answer document

A diligence process asks its own questions in its own order. An answer document
written in advance answers the questions the author expected, which are rarely
the ones asked. A question bank instead lists what this program should expect and
points each question at a file, so that any question arrives with a file already
attached to it.

All four are named rather than hidden, and all four are already in motion. A
diligence process that finds an unanswered question the company had not noticed
draws a conclusion about the company. One that finds an unanswered question the
company has already routed draws a different one.

## The stop conditions

The program stops if the agent cannot be supplied for perioperative
investigational use on any route; if no clinical site will host an
investigator-initiated trial of this shape; if a combination product
determination places the review on a path this company cannot fund; or if the
advisory boundary cannot be demonstrated to a regulator's satisfaction at bench
scale. Any two of the four occurring together is decisive, and the first is
decisive on its own.

Naming them is not pessimism. A funder asked to accept a risk is entitled to know
which risks the company has already identified, and a company that names its own
stop conditions is easier to believe about everything else.
