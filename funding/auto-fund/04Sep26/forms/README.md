Two packs. One is completed on this day and **held** until a site responds. The
other is read against each foundation's published cycle and submitted only inside
one.

## When each is actually submitted

| Pack | Completed | Submitted |
|:--|:--|:--|
| [`form-01-ucsd-iit-concept-intake.md`](form-01-ucsd-iit-concept-intake.md) | On this day | After a site names a principal investigator. A concept form submitted before there is an investigator names no investigator, and the trials office returns it |
| [`form-02-foundation-letter-of-intent.md`](form-02-foundation-letter-of-intent.md) | On this day | Inside an open cycle, and only into a mechanism whose eligibility answer from the day's letters was yes |

Completing a pack and holding it is not wasted work. The gap between "a site said
yes" and "the intake is filed" is where a program loses a month, and closing that
gap in advance is the only way to close it at all.

## What a pack contains

| Block | Contents |
|:--|:--|
| Route and recipients | Where it goes, who receives it, and who answers when it fails |
| Prerequisites | What must be true before the first field is typed |
| Field table | Field label, the answer, and the character limit where the portal states one |
| Narrative fields | The full text to paste, already inside the stated limit, with the count given |
| Budget lines | Where required, reconciled to the $700,000 annual direct cost |
| The hold condition | What has to be true before this pack is submitted |
| Failure modes | The three ways this specific submission goes wrong |
