## Why it is kept

The programme's argument depends on a verifiable chronology, and this
application is the July 7, 2026 point in it. Five days separate it from v2.0,
which is itself the evidence for the productivity claim every v4.4.0 application
makes: one scientist revised a complete NIH application in under a week.

| Date | Artifact | Role in the chronology |
|:--|:--|:--|
| Jan 13, 2026 | [Competition proposal](../supplementary/source-files) | First released proposal |
| Jul 7, 2026 | **This application** | First complete NIH application |
| Jul 12, 2026 | [v2.0](../RFA-RM-27-001-v2) | Revised application, five days later |
| Aug 3, 2026 | [Ten application file sets](../pdac-funding-applications/applications) | Independent-scientist set |
