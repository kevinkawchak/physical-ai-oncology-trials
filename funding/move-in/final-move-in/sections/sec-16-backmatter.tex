\bmhead{Data and Code Availability}

{\raggedright Every work cited to a digital object identifier is openly
deposited. The repository is at
\href{https://github.com/kevinkawchak/physical-ai-oncology-trials}{https://github.com/kevinkawchak/physical-ai-oncology-trials},
version v4.7.0 \cite{repo2026}.\par}

The package is deposited in \texttt{funding/move-in}. That subtree contains the
master prompt filed verbatim and the build output of record in
\texttt{prompts/}; fifteen stage sub-prompts in three directories under
\texttt{sub-prompts/}; the three input artifacts in \texttt{inputs/} with a
README for each; and three complete LaTeX source sets in
\texttt{draft-move-in/}, \texttt{full-move-in/} and \texttt{final-move-in/},
each with its own Overleaf bundle. There is no \texttt{final-move-in/publication}
directory, by instruction.

No raster image is used anywhere in this package. Every rule, badge and mark on
the cover is drawn in the style file. The claim is checkable: a search of the
subtree for a PNG or a JPEG file returns nothing.
