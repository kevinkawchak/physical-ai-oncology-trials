## How v4.4.0 uses these files (Rule 5)

Both PDFs are named as **manual email attachments** in the ten application
`.txt` files under
[`../pdac-funding-applications/applications`](../pdac-funding-applications/applications).
The author attaches them by hand; nothing in this repository sends them.

| Application | Attaches |
|:--|:--|
| 01 NIH Pioneer Award | v2.0, with the local path given explicitly |
| 03 NSF TIP X-Labs | v2.0 |
| 05 NIH SEED SBIR | v2.0 |
| 06 FNIH AMP | v2.0 |
| 10 UC San Diego Moores | v2.0 |

Applications 02, 04, 07, 08, and 09 attach protocol or IND documents instead,
because a funding application is not the strongest artifact for a milestone
agency, a mission platform, a person-based award, a clinical evaluation
programme, or a time-bound organization.
